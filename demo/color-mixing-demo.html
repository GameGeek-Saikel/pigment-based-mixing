混色

颜料基混色模型 PBM（颜料混色）：以 Kubelka–Munk 双流理论为物理骨架，在 sRGB 显示值空间内以两阶段公式工作——K–M 混色核心 + 修复层（逐通道幂律目标 + γ 谐波修正 + 软角色分配）。

PBM 混色核心（全域行为）：① 宽带混色矩阵 M（3×3 行和=1，模拟颜料交叉）；② 吸收/散射解析默认 K=(1−v)²/2、S=max(v,ε)；③ κ=K̄/S̄ 按配比 α 线性叠加（K-M/Duncan 浓度结构）；④ 互吸收修正 κ*=κ̄(1+β_c·s′_j·s′_k)（β 为负 = 散射稀释）；⑤ 响应 R∞=1/(1+s(a₁+a₂s+a₃s²))，s=√κ*，泰勒解析值；⑥ 对称端点压缩 φ（α→0/1 尾端，修复"99% 像 99.9%"的参考收敛差）。

修复层（深色+白 + 互补族）：λ 软角色分配（max 通道判定颜料端/亮端，平局带软混合——模型严格交换对称 F(b,t,α)≡F(t,b,1−α)）；深白门 g=σₖ(w−0.3706)·σₖ(M)·σₖ(maxd−0.0656)（斜率 k=12.584001 共享）；逐通道幂律目标 T_c=p_c+(u_c−p_c)·φ_low(a)^q（q = 软阶跃阶梯（B/G 族）+ 通道残差 + 通道耦合 + 族方向响应）；γ 谐波修正 γ̂(V)·cSat·(1−g)·4a(1−a)·h(a)（统一 19 特征模板 + 双侧色度软衰减，复现黄×蓝、红×绿/青等互补家族）。

常数时间 O(1)：零查找表、零迭代、零条件补丁；α=0/1 恒等；全 σ/smoothstep/clamp 结构、邻域连续（最大单步 ΔE00 1.42）。互补混合不再走色相环——泥色（橄榄/棕/暗紫）是 κ 浓度叠加的自然涌现结果，180° 色相跳跃从构造上不存在。完整形式化与参数估计见 color-mixing-algorithm.md（技术论文）。

对照

RGB 插值固定 50:50 时互补色趋灰（相同机制）；KM(光谱真值)是独立光谱实现：合成颜料光谱（两常数 K–M 模型——吸收 K(λ)=κ_base+ΣA·exp(−((λ−μ)/σ)²)+ΣA/(1+e^±((λ−λ₀)/w)) 与散射 S(λ) 分别建模：半导体型颜料陡峭吸收边（黄/橙/红系）、酞菁红侧吸收、醌吖啶酮双带、群青宽带等真实颜料光谱结构，29 个颜料、10nm/380–750nm。带位置按第一性原理颜料化学给定（发色团跃迁/带隙常数）；幅度/宽度/基底/散射等数值参数标定自公开可得的 BabelColor X-Rite ColorChecker Classic 平均光谱（[Pascale 2012]，30 张色卡、24 个配方色卡补丁；`tools/spectral/calibrate.js` 可复现）经标准两常数 K–M 前向管线（Duncan K/S 分别叠加 → R∞ → D65×CIE 1931 2° 积分 → sRGB），任意 RGB 经确定性 unmix 分解为蓝/品红/黄/白四种合成主颜料浓度（对应 Mixbox 潜空间的 Phthalo Blue / Quinacridone Magenta / Hansa Yellow / Titanium White 结构）并带残差补光（与 Mixbox 潜空间方案同构，但不经训练、不查表）。PBM 卡片下方另显示其与合成光谱真值的 ΔE00。Mixbox（pymixbox 2.0）把 RGB 映射到真实颜料光谱训练的 7 维潜空间做 K–M 混合，是本页的现代参考基准——每块色样下方显示与它的 ΔE00（CIEDE2000，Sharma 2005 行业现行标准：ΔE<1 不可感知、1~2 仔细对比可见、2~4 明显、>4 显著）。

实现

常数时间 O(1)：K–M 核心（3×3 宽带混色 M + 解析 K/S + κ 线性混合 + 互吸收 β + s 域有理式响应 + φ 端点压缩）+ 修复层（λ 软角色分配 + 深白门 g + 逐通道幂律目标（软阶跃阶梯 + 通道残差 + 通道耦合 + 族方向响应）+ γ 谐波修正（19 特征模板 × 27 系数 × cSat 色度软衰减）），零查找表、零迭代、零条件补丁。5 个可调参数经坐标下降对参考混色输出精调（qt2/pB0/pB1/cpl/kc），完整统计与参数估计见 color-mixing-evaluation.html 与 ../docs/color-mixing-algorithm.md。T5 深色+白 专项：mean 2.407 / max 6.1（验收达标：mean<5 / max≤15）；T5E 双侧尾端：mean 2.353 / max 9.5；主三集 mean 3.844 / 3.244 / 2.996；tail 1.713；留出 T3 2.895–3.066、T5-heldout 2.607（max 受互补混色族硬顶限制，如实记录）。
